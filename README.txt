# Сайт Аптеки "ЗдоровьеПлюс"

## Структура проекта:
- index.html - Главная страница
- css/styles.css - Стили
- js/script.js - Скрипты
- images/ - Папка для ваших изображений

## Как запустить:
Просто откройте файл index.html в любом современном браузере.

## Особенности:
- Адаптивный дизайн (Mobile Friendly)
- Чистый код без тяжелых фреймворков
- Используются FontAwesome иконки (CDN)
- Изображения подгружаются с Unsplash (требуется интернет)
